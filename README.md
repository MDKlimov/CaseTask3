# Сумма отрицательных элементов между максимумом и минимумом

## Условие задачи

Дан одномерный массив `A` размерности `N`. Требуется найти сумму отрицательных элементов, расположенных **строго между** максимальным и минимальным элементами массива.

## Файлы проекта

- `sum_negative_between.py` — программа на Python.
- `README.md` — инструкция по запуску и использованию.

## Требования

Python 3. Дополнительные библиотеки не нужны.

## Запуск

Откройте терминал в папке с файлом `sum_negative_between.py` и выполните:

```bash
python sum_negative_between.py
```

Если в вашей системе команда `python` не запускает Python 3, используйте `python3 sum_negative_between.py` (или `py sum_negative_between.py` в Windows).

## Ввод данных

1. Введите положительное целое число `N` — количество элементов массива.
2. В следующей строке введите **ровно `N` целых чисел** через пробел.

Программа проверяет, что `N > 0` и количество введённых элементов равно `N`. При нарушении этих условий возникает ошибка `ValueError`. Нецелочисленный ввод также вызывает ошибку.

## Пример работы

```text
Введите количество элементов массива N: 7
Введите 7 целых чисел через пробел: 4 -2 9 -3 -5 1 -8
Сумма отрицательных элементов между максимумом и минимумом: -8
```

Максимум `9` имеет индекс `2`, минимум `-8` — индекс `6` (нумерация с нуля). Между ними находятся `-3`, `-5`, `1`. Сумма отрицательных элементов: `-3 + (-5) = -8`.

## Алгоритм

1. Считать `N` и массив `A`.
2. Найти индексы первого вхождения максимального и минимального значений.
3. Определить левую и правую границы участка между этими индексами, исключив оба крайних элемента.
4. Перебрать элементы внутри границ и прибавить к сумме только отрицательные значения.
5. Вывести результат.

Порядок расположения максимума и минимума не влияет на работу алгоритма. Если между ними нет отрицательных элементов (в том числе если промежуток пуст), выводится `0`.

**Особый случай:** если максимальное или минимальное значение встречается несколько раз, программа использует **первое вхождение** каждого. Если все элементы равны, оба индекса совпадают и результат равен `0`.

## Сложность

Временная сложность — `O(N)`. Дополнительная память для вычисления суммы — `O(1)` без учёта памяти, необходимой для хранения входного массива.
